🏛️ System Architecture & Low-Latency Design

1. Intrusive Doubly-Linked Lists ($O(1)$ Operations)

Unlike std::list, order queue pointers (prev/next) reside directly inside the cache-aligned Order struct. Cancellations and executions execute in $O(1)$ time with zero heap allocation.

2. Lock-Free SPSC Ring Buffer

Inter-thread communication between the Network I/O thread and the Core Matching thread operates over a cache-padded 1,048,576-slot ring buffer using atomic acquire/release memory semantics (zero mutexes, zero context switches).

3. Cache Alignment & False Sharing Elimination

All core state variables are aligned to 64-byte boundaries with alignas(64) to ensure dedicated L1 cache-lines per CPU core.

4. Deterministic WAL & Event Sourcing

Append-only binary Write-Ahead-Logger (WAL) allows 100% deterministic crash replay and audit recovery with zero data loss.
